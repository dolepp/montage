Privacy Policy

TrueCrime Uploader · Last updated: October 19, 2026

What this application is

TrueCrime Uploader is an internal tool used only by the owner of the Exhibit Tapes YouTube channel to manage that channel. It is not distributed to or used by anyone else.

Data we access

With the channel owner's consent through Google OAuth, the tool accesses the owner's own YouTube account using YouTube API Services:

  • uploading, editing and deleting the channel's videos, thumbnails and playlists;
  • reading the channel's YouTube Analytics and revenue reports.

It does not access data of other YouTube users, and it does not collect personal information from viewers.

How data is stored and used

OAuth tokens are stored only on the owner's own computer, in a file readable only by the owner's user account. Analytics data is used only to plan and improve the channel's content. No data is sold, shared with third parties, or used for advertising.

Google and YouTube

This tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of your data is described in the Google Privacy Policy.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. When access is revoked, stored tokens stop working and are deleted.
